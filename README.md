# PROCESO DE INSTALACIÓN
## Paso Nº1
Tener instalado VS Code o similar
## Paso Nº2 
Descargar la extensión de Live Server
## Paso Nº3
Clonar el repositorio
```
git clone https://github.com/noxuxgg/Pasankalla
```
## Paso Nº4
Dirigirse al archivo 'index.html' y hacer clic derecho -> 'Open with Live Server'
